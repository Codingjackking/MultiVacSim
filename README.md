# VaccineSim

<!-- VaccineSim is an innovative research project focused on optimizing multi-vaccine distribution through the use of advanced reinforcement learning techniques. By developing a modular data preprocessing pipeline, VaccineSim is able to efficiently select and clean high-quality COVID-19 and influenza datasets, overcoming challenges such as memory constraints and data inconsistencies. The project integrates sophisticated feature engineering, synthetic data generation, and graph-based routing algorithms to create a dynamic reinforcement learning environment that adapts to real-time public health data. This approach aims to ensure more equitable and efficient vaccine allocation, ultimately improving outcomes during public health crises. -->
